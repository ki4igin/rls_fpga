# Протокол общения по DMA
## Основной режим

### Обозначения

M - прореживание (20).

Offset и Size в битах

### Структура выходного заголовка

| Offset | Size   | Name                       | Description                           |
| - | - | - | - |
| 0      |   64   | Делимитер 1                | 0xfedcba9801234567                    |
| 64     |   32   | Номер формуляра            | последнего принятого                  |
| 96     |   64   | Время                      | последнего принятого                  |
| 160    |   16   | Канал                      | если есть в типе сообщения            |
| 176    |   16   | Источник                   | далее source                          |

### Структура основного сообщения

source = 0

Повторяется в одном пакете по числу обнаружений

Отправляется на каждые M принятых входных буферов, если было обнаружение

```
+------------------+--------------------------+-------------------------------------+-----------------------+-------------------------------------+
| Шумовой формуляр | Компенсационный формуляр | Подзаголовок формуляров обнаружения | Формуляры обнаружения | Формуляры дальности с подзаголовком |
+------------------+--------------------------+-------------------------------------+-----------------------+-------------------------------------+
```
### Структура шумового формуляра

| Offset | Size | Name                       | Description                             |
| - | - | - | - |
| 0 | 32 | Номер посылки | айди входного формуляра, по которому посчитаны шумовые |
| 32 | 32 * 8 | ФАП | Шумовой формуляр ФАП |
| 32 + 32 * 8 | 32 * 8 | ЛОУ | Шумовой формуляр ЛОУ |
